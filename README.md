# bcoe-site
BCoE website repository

## Structure

Plain HTML and CSS, no build step. Upload the files as they are to the web host.

- `index.html` home
- `bookings/index.html` bookings
- `contact/index.html` contact
- `assets/css/style.css` shared styles
- `robots.txt`

All page text is placeholder ("Placeholder, content to come") until real content is supplied.
